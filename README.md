Object Detection using YOLOv8
Overview

This project implements an Object Detection System using the YOLOv8 model. It detects objects from images, videos, and live webcam streams using a pretrained YOLOv8 model. The project is developed in Python using Ultralytics YOLOv8 and OpenCV.

Features
Real-time webcam object detection
Image object detection
Video object detection
Bounding boxes with class labels and confidence scores
Simple menu-driven interface
Technologies Used
Python 3.x
YOLOv8 (Ultralytics)
OpenCV
Installation

Install the required libraries:

pip install ultralytics opencv-python matplotlib
Run the Project
python detect.py

Choose one of the following options:

1 – Webcam Detection
2 – Image Detection
3 – Video Detection
Output

The system displays detected objects with bounding boxes, class names, and confidence scores. Press Q to exit webcam or video detection.

Conclusion

This project demonstrates object detection using the pretrained YOLOv8 model, providing an easy and efficient solution for detecting objects from images, videos, and webcam streams.
